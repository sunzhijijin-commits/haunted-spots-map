# 日本心霊スポットマップ 🌙👻

日本全国の有名な心霊スポットを地図上で確認できるインタラクティブなウェブサイトです。

## 特徴

- 📍 **インタラクティブな地図**: Leaflet.jsを使用した直感的な地図表示
- 🔍 **検索機能**: スポット名や場所で簡単に検索
- 🏷️ **カテゴリーフィルター**: 廃墟、トンネル、峠、病院などでフィルタリング
- ⚠️ **危険度表示**: 各スポットの危険度を色分けで表示（高=赤、中=オレンジ、低=緑）
- 📱 **レスポンシブデザイン**: スマートフォンやタブレットにも対応
- 🎨 **モダンなUI**: グラデーションとアニメーションを使用した美しいデザイン

## 使い方

1. ブラウザで `index.html` を開く
2. 地図上のマーカーをクリックして詳細情報を確認
3. 検索ボックスでスポットを検索
4. カテゴリーボタンでフィルタリング

## カスタマイズ

### 新しいスポットの追加

`script.js` の `hauntedSpots` 配列に新しいオブジェクトを追加してください：

```javascript
{
    id: 13,
    name: "スポット名",
    lat: 緯度,
    lng: 経度,
    type: "カテゴリー", // 廃墟、トンネル、峠、病院、その他
    location: "都道府県市区町村",
    danger: "危険度", // 高、中、低
    description: "説明文"
}
```

### カテゴリーの追加

1. `index.html` のフィルターボタンに新しいボタンを追加
2. `script.js` の `filterSpots` 関数は自動的に対応
